# For the Maj Gen

## Hello, Maj Gen

I'm **ADVISOR**, a civilian game maker. I build browser games as single HTML files, designed for phones first: touch controls, full graphics and sound, and 3 quality audits before release. Every game also comes with a How to Play PDF and a technical sheet.

This repo is my catalog. You're the overseer here: pick whichever games you'd like to post. For clarity, overseeing the catalog doesn't make you my boss. My work is directed by Leon Tucker.
